# randy-huntington

一个把**兰迪·亨廷顿（Randy Huntington）**训练理念做成自我诊断工具的 Skill。

> 兰迪是带出迈克·鲍威尔 8.95m 跳远世界纪录（1991，至今未被打破）、威利·班克斯三级跳世界纪录，以及苏炳添 9秒83 亚洲纪录的美国田径教练。他自己说：「我是 2% 的教练，其余的 98% 来自科学。」

---

## 这是什么

把训练数据告诉它，它按兰迪的**冠军模型五步法**——看到差距 → 结构化找原因 → 确定核心原因 → 寻找解决方法 → 复盘——定位你的问题，然后给出**可执行的调整方案**。

不是一份通用训练计划。兰迪整套方法论的内核恰恰是"看个体数据定方案"，所以这个 skill 的价值不在"告诉你练什么"，在于**逼你先看清自己差在哪、以及还缺哪些数据**。

它**不会**：诊断伤病、开康复方案、给"练这个就能跑进 X 秒"的承诺。

## 三条硬原则

| 原则 | 含义 |
| --- | --- |
| **数据不足不开方案** | 缺关键数据时先要数据；拿不到就只能给方向，不给参数，并说明为什么 |
| **不诊断伤病** | 疼痛、损伤、麻木一律转介医生，不建议带伤训练 |
| **标注置信度** | 每条结论必须标 `【已测】`/`【推断】`/`【待测】`，禁止把推测讲成事实 |

## 关于可信度

这个项目最在意的一件事，是**把"兰迪本人说的"和"别人替他说的"分开**。

| 等级 | 含义 | 来源 |
| --- | --- | --- |
| **A** | 本人一手材料 | SimpliFaster 深度访谈、Just Fly Sports 播客问答、Training & Conditioning 1991《The Ultimate in Speed》与 2015 回访、苏炳添本人论文 |
| **B** | 权威媒体深度报道 | 南方人物周刊《2% 的教练 98% 的科学》、人民日报海外版 |
| **C** | 网络二手整理，**未见一手出处** | 各类"兰迪体系解读"文章 |

网上流传的某些整理包含极为精确的参数（呼吸同步的心率区间、冷热交替的分钟配比、PNF 的秒数轮数、高低神经日的具体星期排布），**但没有一手出处**——它们比兰迪本人说的还"详细"，这本身就是信号。本项目把这些内容单独隔离并标注「待核实」，绝不让它污染 A 级内容。逐条对照见 `references/08-出处与置信度.md`。
