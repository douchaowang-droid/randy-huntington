# 02 · 技术模型与生物力学诊断

主要来源：SimpliFaster 深度访谈（Freelap Friday Five）〔A〕、苏炳添论文〔A〕、中文报道〔B〕。

这是整个体系里最"硬"的部分，也是自我诊断最有抓手的地方。

---

## 一、为什么要"技术模型"〔A〕

> "I consider it very important that my athletes move toward a technical model. I think it's important that athletes **'look like' the great ones**."

大意：**让运动员"看起来像"那些伟大选手**，非常重要。技术上他关注的东西其实很常规——但重点在于**去查明运动员是"怎么"实现这些指标的**。

关键词是那个 **how**。同样的步长，有人靠步频堆出来，有人靠蹬伸效率，两者的训练方向完全不同。

---

## 二、三个核心指标〔A〕

| 指标 | 他怎么看 |
| --- | --- |
| **触地时间**（ground contact time） | 关键指标之一。他提到 **0.09 秒**这个量级时，已经进入**非自主运动（nonvolitional）**的领域——意思是那个阶段你来不及"想"，靠的是反射和刚度 |
| **步长**（stride length） | 在**最大速度段（40–70m 之间）**测量，并与运动员的**人体测量数据**作对比 |
| **步频**（stride frequency） | 与步长是一对，要一起看配比，不能单看一个 |

还要看**前摆到落地、落地到前摆**（frontside → ground → ground → frontside）的**恢复力学**——这一环是达到最优步长的一部分。

机制解释：必须有力量向下施加到跑道，同时肢体离地时要有正确的准备动作。**如果骨盆姿态正确**（由它上面的解剖结构决定），且脚正确落地，你就能通过髋屈肌得到一个**牵张反射（stretch reflex）**，帮助完成这些恢复动作。

他引用了 Gideon Ariel 的一句话〔A〕：

> 「肌肉设置关节以利用可用的弹性特性。」

（muscles set up joints to take advantage of the elastic properties available）

## 三、人体测量学：算你的最优步长〔A〕

他测量的解剖数据：

- **大转子长度**（greater trochanter length）
- 身高
- 股骨长度
- 胫骨长度
- **内踝到拇趾**的距离

这些解剖数据**可以估算运动员的最优步长应该是多少**；更重要的是，**这些测量之间的比值**能提示需要做什么样的训练——比如需要什么样的力量训练，才能让这个杠杆系统尽可能接近"最优比值"那套系统。

### 苏炳添案例〔A〕

- 大转子长度只有 **0.895 米**，相当于一个身材较矮的女性
- 因此**步长天生长不了**
- 但他的步频曾经**超过每秒 5 步**，非常高
- 处理方式：**主动降低步频，让步长增加**，把两个指标拉向更优的组合

这是很反直觉的一条：**"频率高"不一定是优势**，要看你的形态该配什么步长。

## 四、他实际改过苏炳添什么

**2014 年**：通过数据分析发现苏炳添 100m 存在**节奏感缺失**的问题，于是**调整了起跑器上双脚的位置**〔B〕。这是他第一次被这套技术手段改变——之后 2015 年跑出 9秒99。

**另一批被发现并修正的技术问题**〔B〕：起跑姿势不合理、步长过短、扒地技术欠佳。

**改完之后**〔B〕：起跑姿势更舒展、步长明显增加、最大速度更快、呼吸节奏也更精细。

## 五、自测方法（没有实验室怎么做）

他的原话里有一句对自练者很友好的话〔A〕：1991 年他还在用**牛皮纸（butcher paper）**量步长，那依然有效，只不过现在用视频快得多、方便得多。

**你需要的**：一部手机（慢动作）+ 一段有标尺的跑道 + 一个帮忙拍的人。

| 指标 | 自测方法 | 精度提示 |
| --- | --- | --- |
| 步长 | 最大速度段（40–70m）地面放标尺/胶带，慢视频逐帧看两侧落点间距；取 3–5 步平均 | 较高 |
| 步频 | 同段视频里数步数 ÷ 时间 | 较高 |
| 大转子长度 | 站立位，量髋骨最突出处到膝外侧的垂直高度 | 高（自己量即可） |
| 触地时间 | 只能靠高速摄像逐帧估算（30fps 拍不出，需 120fps 以上） | **低，标 `【推断】`** |
| frontside→ground 时间 | 同上，逐帧 | 低 |

**触地时间不要硬测。** 手机 + 30fps 估出来的数没有决策价值，宁可标成 `【待测】`，先去测步长步频这种能拿准的。

## 六、诊断顺序（自用版）

```
1. 量大转子、身高 → 算出你的"形态允许的步长区间"
2. 测最大速度段步长、步频 → 看你在不在这个区间里
3. 不在区间里，再问：是姿态问题，还是力量问题？
4. 姿态问题 → 技术训练优先（他：先训练动作）
5. 力量问题 → 才考虑上力量（而且要先确认技术动作能做对）
```

第 3 步是"结构化找原因"的核心分岔，别跳过。
