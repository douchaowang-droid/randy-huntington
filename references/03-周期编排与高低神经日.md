# 03 · 周期编排与高低神经日

**注意来源等级**：这一份里的**框架**（高/低强度分开、训练内充分休息、速度掉即停）来自 A 级来源；但**具体的星期排布和分钟数**来自网络二手整理（C 级），**引用时必须标注"待核实"**。

---

## 一、A 级：核心框架（可直接用）

### 1. 训练内：高质量 → 完全恢复 → 再高质量〔A〕

他在播客里说得非常直接：

> "I rarely go above 95% (of max speed) (in flying sprints in training)"
> 「我在训练中的行进间跑，很少超过最大速度的 95%。」

以及他在力量训练上的原则：**在运动员能做出目标技术动作之前，不做太重。**

自用版的可执行规则：
- 速度训练的每一次重复，**强度要接近你的最好水平**，不是"跑到累"
- 组间必须**完全恢复**（具体秒数见 C 级部分，或自己按"感觉恢复了再跑下一组"）
- **一旦发现速度下降，立即停止这一项**——速度下降说明已经不练速度了，在练疲劳

### 2. work + rest = adaptation〔A〕

> 见 `00-理念总纲.md` 第 3 条。**这是编排的总纲**：高强度日之间必须插恢复日。

### 3. 他的训练日类型〔A/B〕

从他的访谈内容可以确定他使用这些手段：
- **速度/技术日**：短跑、行进间跑、变换负荷跑、技术训练
- **力量日**：雪橇、1080、clean 之类的爆发力举（看功率不看重量）
- **恢复**：Omegawave 监测 → 决定当天练什么

## 二、C 级：二手整理的高-低模式（待核实）

以下内容来自网络二手整理文章，**未在他本人的一手采访中找到完整对应**，请当作参考框架而非他的原话：

### 高低神经日（High/Low System）

| 日程 | 内容 | 目的 |
| --- | --- | --- |
| 高神经日（示例：Mon / Wed / Sat） | 短跑、跳跃、最大力量输出、牵张反射训练 | 建立强神经刺激 |
| 低神经日（示例：Tue / Fri） | 有氧恢复、缓慢动态技术、低强度力量、瑜伽/拉伸/按摩 | 支持神经恢复 |
| 休息日（示例：Thu 或 Sun） | 完全休息 | 中枢与激素恢复 |

### 他整理的四条训练原则（二手）

| 原则 | 关键点 |
| --- | --- |
| 高质量原则 | 每次输出都应接近最佳速度或最佳力量，不允许在疲劳状态下硬撑 |
| 低次数、足恢复 | 训练内保证充足间歇；每周安排神经恢复日 |
| 不训练疲劳，而训练巅峰神经状态 | 宁可少做 |
| 神经-肌肉时序优先于肌肉力量输出 | 技术质量优先于力量大小 |

### 训练内的具体参数（二手）

- 短跑质量组示例：每次重复 ≥ **95%** 速度阈值；两组间休息 **6–15 分钟**；速度下降立即停止
- 神经恢复手段：低强度慢跑 + 呼吸同步（8–12 分钟 / 110–130 bpm）；PNF 拉伸（每组 8–12 秒收缩 / 3–5 轮）；脊柱放松 5–10 分钟；冷热交替（冷 3 分钟 / 热 4 分钟 / 4 回合）
- 「睡眠质量 = 神经再生能力的根本来源」

## 三、自用版：一周怎么排（业余可执行）

前提：每周能练 **3–5 天**，且不是专业运动员。**所有量都要降档。**

```
原则：
1. 高强度（速度/大力量）之间至少隔 48 小时
2. 一周高强度日不超过 3 天
3. 高强度日之后的那天，要么休息，要么只做低强度
4. 速度、力量、跳跃不要全堆在同一天（除非量很小）
5. 有一整个完全休息日
```

**3 天版（最低可行）**

| 日 | 内容 |
| --- | --- |
| 周二 | 速度/技术（高） |
| 周四 | 力量 + 低强度有氧（中） |
| 周六 | 速度/技术（高） |
| 其余 | 休息或散步 |

**5 天版（进阶）**

| 日 | 内容 |
| --- | --- |
| 周一 | 速度/技术（高神经） |
| 周二 | 低强度有氧 + 灵活性（低） |
| 周三 | 力量/爆发力（高神经） |
| 周四 | 休息 |
| 周五 | 速度/技术（高神经） |
| 周六 | 低强度有氧 + 技术练习（低） |
| 周日 | 休息 |

**判据（用来验证编排对不对）**：
- 高强度日当天，第一组的质量是否稳定？掉得厉害 → 上次恢复不够
- 连续两周成绩没动，但主观很累 → 先按 `05-恢复与监测.md` 处理恢复，不是加量
- 晨脉连续 3 天比基线高 5–8 次/分 → 当天降档
