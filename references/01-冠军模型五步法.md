# 01 · 冠军模型五步法

来源：苏炳添本人论文中记述、江南时报报道引述，媒体转述为"冠军模型五步法"〔A/B〕。

核心思路：**研究该领域"最优者（冠军）"的策略与细节，然后找出自身差距，寻找提升自己最优的"冠军路径"。**

---

## 五步

### 第一步：看到差距
识别当前状态与目标之间的差距。

**自用版注意**：差距必须是可量化的差，不是形容词。
- ❌「我速度不够快」
- ✅「我最大速度段步长 1.85m，同身高优秀选手在 2.05–2.10m 区间，差 0.2m」

差距要站在**同项目、同性别、可比的形态条件**下比。用你的大转子长度和身高去比，而不是直接比苏炳添的数字。

### 第二步：结构化思考法寻找原因
系统性地分析差距背后的原因。

自用版建议按**四个维度**列候选，先把候选列全，不要急着筛：

| 维度 | 候选原因 |
| --- | --- |
| 体能 | 最大力量、发力速率（RFD）、下肢刚度、股后肌群、踝关节力量 |
| 技术 | 起跑姿势、步长/步频配比、触地时间、扒地质量、骨盆姿态、躯干稳定 |
| 恢复 | 睡眠、周负荷、连续高强度天数、静息心率 |
| 编排 | 高低神经日是否错开、测试频率、周期安排 |

### 第三步：确定原因
找出主要的核心原因——收敛到 1–2 个。

**这是最容易偷懒的一步。** 必须回答："为什么是它，而不是候选里的其他几个？"没有数据支撑的，标 `【推断】`，不要伪装成结论。

### 第四步：寻找解决方法
针对核心原因，制定可行的解决方案。

每条方案四要素齐全：

```
做什么 + 强度或量 + 停止条件 + 风险
```

**缺任何一样都不算方案。** 尤其"停止条件"——这是他体系里非常有特色的东西（见 `04-速度与力量手段.md`：速度一下降就立即停止）。

### 第五步：复盘
对方案实施后的结果进行反思和总结，持续改进。

**自用版注意**：复盘要有**预先定好的观察窗口和判断指标**，不能事后找感觉。见 `assets/周期编排模板.md` 末节的复盘栏。

## 苏炳添版本的实际执行（作为样板）

他被诊断出的问题清单，可以直接当作"结构化诊断"的范例〔B〕：

**体能层面**
- 股后肌群力量不足
- 踝关节力量偏弱
- 发力速率较慢

**技术层面**
- 起跑姿势不合理
- 步长过短
- 扒地技术欠佳

**干预方式**：精确的仪器测量 + **运动员主观反馈**结合，**灵活调整训练负荷**，避免伤病和过度训练〔B〕。

**结果**：起跑姿势更舒展、步长明显增加、最大速度更快、呼吸节奏更精细〔B〕。

## 自用版五步问句（可直接照着自问）

1. **差距**：我现在的哪几个数字，和同项目优秀者差多少？
2. **原因**：我列了哪些候选？各自有什么证据？
3. **核心**：如果只能改一件事，改哪件？为什么？
4. **方法**：怎么做、做多少、什么时候停、有什么风险？
5. **复盘**：多久后看什么？什么信号说明该改方案了？
