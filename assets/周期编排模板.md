**降档提醒**：兰迪的原始体系面向国家队运动员（一天多练、有完整保障团队）。业余自练请按 `references/07-争议与边界.md` 的降档原则处理——**量减半、频率降低、强度（质量）保留**。

## 二、一周排布（5 天版 · 进阶）

| 日 | 类型 | 内容 |
| --- | --- | --- |
| 周一 | **高神经** | 速度 / 技术 |
| 周二 | 低 | 有氧 + 灵活性 |
| 周三 | **高神经** | 力量 / 爆发力 |
| 周四 | 休息 | 完全休息 |
| 周五 | **高神经** | 速度 / 技术 |
| 周六 | 低 | 有氧 + 技术练习 |
| 周日 | 休息 | 完全休息 |

> 高强度日之间至少间隔 48 小时；一周高强度不超过 3 天。

## 三、单次速度课的结构（照他的"训练内"原则）

```
1. 热身（充分，含动态活动）
2. 技术练习（低强度）
3. 主项：速度重复
   - 每次重复：接近个人最好水平（训练中不反复冲极限，参考"极少超过 95%"）
   - 组间：完全恢复（宁可多歇）
   - 停止条件：速度出现下降 → 立即结束这一项
4. 收操
```

**记住他的两条**：
- 「不是练到累，而是练到每次输出都接近完美」
- 力量训练的前提是**技术动作能做对**，做不到就回去练技术

## 四、测试安排

| 测试 | 频率 | 说明 |
| --- | --- | --- |
| Flying 30 | **最多每 6 周一次，通常 2 个月** | 他的核心测试 |
| 纵向固定测试（立定跳远等） | 每周同一时间 | 业余条件下最有用的恢复/进步指标 |
| 完整体测 | 每周期一次 | 别天天测 |

**别把测试练成训练。** 频繁测试本身就是负荷。
